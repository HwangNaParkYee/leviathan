# API 명세서: getAllMyProblemNumbers

## 기본 정보
- **API 엔드포인트**: GET /api/findMyProblem
- **컨트롤러**: ProblemController
- **서비스 메소드**: ProblemService.getAllMyProblemNumbers()
- **인증 요구사항**: 로그인 필요 (JWT 토큰 필요)

## 요청 (Request)

### 헤더 (Headers)
- **Authorization**: JWT 인증 토큰 (쿠키에 포함)

### 매개변수 (Parameters)
- 없음

## 응답 (Response)

### 성공 응답
- **상태 코드**: 200 OK
- **응답 형식**: JSON
- **응답 구조**:
  ```json
  [
    {
      "problemId": Long,
      "problemNumber": Long,
      "title": String
    },
    ...
  ]
  ```

### 응답 필드 설명
- **problemId**: 문제의 고유 식별자 (Long)
- **problemNumber**: 문제 번호 (Long)
- **title**: 문제 제목 (String)

### 실패 응답
- **상태 코드**: 401 Unauthorized
  - **원인**: 로그인하지 않은 사용자가 API 호출 시
  - **응답 메시지**: "로그인을 해주세요."

- **상태 코드**: 500 Internal Server Error
  - **원인**: 서버 내부 오류
  - **응답 메시지**: 오류 메시지

## 기능 설명
이 API는 현재 로그인한 사용자가 생성한 모든 문제 목록을 반환합니다. 사용자는 JWT 토큰을 통해 인증되며, 인증된 사용자의 문제만 반환됩니다. 반환되는 정보는 각 문제의 ID, 문제 번호, 제목을 포함합니다.

## 사용 예시

### cURL 요청 예시
```bash
curl -X GET "http://서버주소/api/findMyProblem" \
     -H "Cookie: accessToken=YOUR_JWT_TOKEN" \
     -H "Content-Type: application/json"
```

### 응답 예시
```json
[
  {
    "problemId": 1,
    "problemNumber": 101,
    "title": "배열의 합 구하기"
  },
  {
    "problemId": 2,
    "problemNumber": 102,
    "title": "문자열 뒤집기"
  }
]
```
